# Network Traffic Classification

A Django-based web application for Network Traffic Classification.

## 📊 Datasets Used

The following datasets are included in this project for checking, testing, and validation of the Network Traffic Classification system.

### 🔹 `Book2.csv`
Additional network traffic dataset used for testing and validation.

### 🔹 `multiattack.csv`
Contains multiple attack traffic data used for checking and evaluating attack classification.

### 🔹 `normal multi.csv`
Contains normal network traffic data used for checking the classification system.
